# service-runtime — delta

## MODIFIED Requirements

### Requirement: Запуск с конфигурацией из окружения
Сервис SHALL читать конфигурацию из переменных окружения при старте: адрес прослушивания HTTP, имя окружения (development/staging/production), уровень логирования, строки подключения PostgreSQL и Redis, базовый URL сервиса, URL метаданных IdP, секрет подписи RelayState, базовый URL frontend и параметры сессий (имя cookie, idle-timeout, абсолютный срок, лимит одновременных сессий). Для отсутствующих переменных SHALL применяться безопасные значения по умолчанию, пригодные для локальной разработки; вне development параметры подключений, URL и секреты SHALL быть обязательными — их отсутствие является ошибкой старта. Вне development секрет подписи RelayState SHALL быть не короче 32 символов и не совпадать с dev-значением по умолчанию. При запуске внутри Kubernetes имя окружения SHALL быть задано явно: его отсутствие является ошибкой старта, а не development по умолчанию.

#### Scenario: Старт с валидной конфигурацией
- **WHEN** процесс запускается с корректными переменными окружения
- **THEN** сервис начинает слушать указанный адрес и пишет в лог факт старта с именем окружения

#### Scenario: Старт с невалидной конфигурацией
- **WHEN** переменная окружения содержит недопустимое значение (например, нераспознанный уровень логирования)
- **THEN** процесс завершается с ненулевым кодом выхода и понятным сообщением об ошибке, не начиная принимать трафик

#### Scenario: Отсутствие обязательных параметров вне development
- **WHEN** процесс запускается с `APP_ENV=production` без строки подключения PostgreSQL, Redis или секрета RelayState
- **THEN** процесс завершается с ненулевым кодом выхода и сообщением, какие переменные отсутствуют

#### Scenario: Слабый секрет RelayState вне development
- **WHEN** процесс запускается с `APP_ENV=staging` и секретом RelayState короче 32 символов или равным dev-значению по умолчанию
- **THEN** процесс завершается с ошибкой конфигурации

#### Scenario: APP_ENV не задан в Kubernetes
- **WHEN** процесс запускается в поде Kubernetes без переменной `APP_ENV`
- **THEN** процесс завершается с ошибкой конфигурации, не переходя в development
