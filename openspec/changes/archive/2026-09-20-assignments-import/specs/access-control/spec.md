## MODIFIED Requirements

### Requirement: Bootstrap-управление через CLI
До появления API управления сервис SHALL предоставлять CLI-команды: назначение и снятие роли пользователю (по email и `app/role`), декларативная загрузка приложений, ролей и permissions из файла, массовый импорт назначений ролей из файла. Загрузка SHALL быть идемпотентной и MUST NOT удалять назначения пользователей. CLI-операции SHALL записываться в журнал с актором `cli`.

Импорт назначений SHALL принимать файл со списком записей «пользователь (глобальный ID или email) → роли `app/role`», SHALL валидировать файл целиком до первой записи в базу, SHALL назначать роли одного пользователя в одной транзакции и SHALL быть идемпотентным: уже назначенная роль не изменяется и не журналируется. Запись с неизвестным пользователем или ролью SHALL откатываться целиком, не мешая остальным; команда SHALL печатать отчёт по каждой записи и завершаться ненулевым кодом, если применились не все. Режим проверки без записи SHALL показывать тот же отчёт без изменений в базе.

#### Scenario: Идемпотентная загрузка
- **WHEN** файл с приложениями и ролями загружается дважды
- **THEN** второй запуск не создаёт дубликатов и завершается успешно

#### Scenario: Загрузка сужает состав роли
- **WHEN** из файла исчез permission, ранее входивший в роль
- **THEN** состав роли приводится к файлу, а назначения ролей пользователям сохраняются

#### Scenario: Повторный импорт назначений
- **WHEN** файл назначений импортируется второй раз без изменений
- **THEN** назначения не дублируются, журнал не получает новых записей, команда завершается успешно

#### Scenario: Запись с неизвестной ролью
- **WHEN** у одного пользователя в файле указаны существующая и несуществующая роль, а у другого — только существующие
- **THEN** первому пользователю не назначается ни одна роль из записи, второму назначены все, отчёт называет отказ, код выхода ненулевой

#### Scenario: Невалидный файл
- **WHEN** в файле есть запись без ролей, с обоими или ни одним из `id`/`email`, либо с ссылкой не вида `app/role`
- **THEN** команда завершается ошибкой до любых изменений в базе

#### Scenario: Проверка без записи
- **WHEN** импорт запущен в режиме проверки
- **THEN** отчёт печатается, назначения и журнал не меняются
