# schema-docs

## Why

Владелец попросил аналог Rails `annotate` — «открыл и увидел схему». В
Go структура и есть объявление колонок, но полной картины таблиц, связей
и ограничений в одном месте нет; при этом каждая таблица и колонка уже
снабжена `COMMENT ON` (правило AGENTS.md). tbls превращает эти
комментарии в markdown и ER-диаграммы из живой базы; CI следит, чтобы
документация не отставала от миграций. Решение владельца 14.09.

## What Changes

- `tbls` в `mise.toml` (aqua-бэкенд, без ручной установки).
- `.tbls.yml`: DSN из `DATABASE_URL` с dev-умолчанием, вывод в
  `docs/schema/`, ER в mermaid (текст, без graphviz), `goose_db_version`
  исключена.
- `mise run schema:docs` — миграция локальной базы и генерация;
  `mise run schema:check` — `tbls diff`, падает при расхождении.
- `docs/schema/` закоммичена: README со списком таблиц и ER, файл на
  таблицу с колонками, комментариями, ограничениями и индексами.
- CI-джоб `schema-docs`: PostgreSQL как сервис, миграция, `tbls diff`.
- README: раздел.

## Impact

Только dev-инструменты, документация и CI. Рантайм не затронут.
