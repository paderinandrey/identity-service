# web-sessions — delta

## MODIFIED Requirements

### Requirement: Внутренняя проверка сессии
Сервис SHALL предоставлять внутренний HTTP endpoint проверки сессии для ext-auth входного proxy по пути `/internal/session/validate`. Endpoint SHALL отвечать независимо от HTTP-метода запроса и независимо от того, дописан ли к пути суффикс исходного запроса: ext-auth воспроизводит метод исходного запроса и трактует настроенный путь как префикс, поэтому привязка к одному методу или к точному пути отклоняла бы проверку для всех запросов. По cookie из запроса он SHALL возвращать 200 с контекстом пользователя (глобальный ID, email) и его эффективными правами в формате `application:permission` (через запятую) в ответных заголовках либо 401. Недоступность зависимостей MUST NOT приводить к ответу 200 (fail-close). Endpoint MUST NOT быть достижим через публичную маршрутизацию.

#### Scenario: Валидная сессия
- **WHEN** proxy передаёт запрос с cookie действующей сессии активного пользователя
- **THEN** ответ 200 содержит заголовки с глобальным ID, email и эффективными правами пользователя

#### Scenario: Проверка методом исходного запроса
- **WHEN** ext-auth обращается к endpoint методом POST (зеркалируя `POST /graphql`) с cookie действующей сессии
- **THEN** ответ такой же, как для GET: 200 с заголовками контекста

#### Scenario: Путь с дописанным суффиксом исходного запроса
- **WHEN** ext-auth обращается по пути `/internal/session/validate/graphql` (настроенный путь как префикс плюс исходный) с cookie действующей сессии
- **THEN** ответ такой же, как для точного пути: 200 с заголовками контекста

#### Scenario: Пользователь без назначенных ролей
- **WHEN** у пользователя действующей сессии нет ни одной роли
- **THEN** ответ 200 содержит идентификационные заголовки и пустой заголовок прав

#### Scenario: Недействительная сессия
- **WHEN** cookie отсутствует, сессия истекла или пользователь деактивирован
- **THEN** ответ 401 без контекста пользователя

#### Scenario: Redis недоступен
- **WHEN** хранилище сессий недоступно при проверке
- **THEN** ответ является ошибкой, а не 200; запрос не пропускается как авторизованный
