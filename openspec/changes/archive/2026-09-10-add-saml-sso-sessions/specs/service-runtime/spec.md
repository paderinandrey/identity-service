# service-runtime — delta

## MODIFIED Requirements

### Requirement: Запуск с конфигурацией из окружения
Сервис SHALL читать конфигурацию из переменных окружения при старте: адрес прослушивания HTTP, имя окружения (development/staging/production), уровень логирования, строки подключения PostgreSQL и Redis, базовый URL сервиса, URL метаданных IdP, секрет подписи RelayState, базовый URL frontend и параметры сессий (имя cookie, idle-timeout, абсолютный срок, лимит одновременных сессий). Для отсутствующих переменных SHALL применяться безопасные значения по умолчанию, пригодные для локальной разработки; вне development параметры подключений, URL и секреты SHALL быть обязательными — их отсутствие является ошибкой старта.

#### Scenario: Старт с валидной конфигурацией
- **WHEN** процесс запускается с корректными переменными окружения
- **THEN** сервис начинает слушать указанный адрес и пишет в лог факт старта с именем окружения

#### Scenario: Старт с невалидной конфигурацией
- **WHEN** переменная окружения содержит недопустимое значение (например, нераспознанный уровень логирования)
- **THEN** процесс завершается с ненулевым кодом выхода и понятным сообщением об ошибке, не начиная принимать трафик

#### Scenario: Отсутствие обязательных параметров вне development
- **WHEN** процесс запускается с `APP_ENV=production` без строки подключения PostgreSQL, Redis или секрета RelayState
- **THEN** процесс завершается с ненулевым кодом выхода и сообщением, какие переменные отсутствуют

### Requirement: Readiness-эндпоинт
Сервис SHALL отвечать на `GET /readyz` статусом 200, когда готов принимать трафик: HTTP-сервер запущен, подключения к PostgreSQL и Redis установлены и проходят проверку. После начала graceful shutdown или при потере обязательной зависимости endpoint SHALL возвращать 503.

#### Scenario: Сервис готов
- **WHEN** сервис запущен, PostgreSQL и Redis доступны и не идёт остановка
- **THEN** `GET /readyz` возвращает 200

#### Scenario: Сервис останавливается
- **WHEN** сервис получил сигнал остановки и начал graceful shutdown
- **THEN** `GET /readyz` возвращает 503, чтобы балансировщик прекратил направлять новые запросы

#### Scenario: Потеря зависимости
- **WHEN** проверка подключения к PostgreSQL или Redis не проходит
- **THEN** `GET /readyz` возвращает 503, при этом `GET /healthz` продолжает отвечать 200
