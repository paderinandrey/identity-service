# web-sessions — delta

## ADDED Requirements

### Requirement: Уничтожение всех сессий пользователя
Сервис SHALL поддерживать немедленное уничтожение всех сессий пользователя (по индексу сессий); операция SHALL использоваться при деактивации через провижининг. После уничтожения прежние идентификаторы сессий SHALL быть недействительны.

#### Scenario: Все сессии отозваны
- **WHEN** для пользователя с несколькими активными сессиями вызывается уничтожение всех сессий
- **THEN** каждый прежний идентификатор сессии получает 401, индекс сессий пользователя пуст
