# cleanenv-config

## Why

Конфигурация читается вручную: 25 переменных, для каждой отдельный
`os.Getenv`, разбор и сообщение об ошибке в `internal/config/config.go`,
а описание и значения по умолчанию продублированы в таблице README.
Каждая новая переменная требует правки в четырёх местах, и ничто не
проверяет, что README совпадает с кодом. Владелец попросил перевести
разбор на `github.com/ilyakaznacheev/cleanenv`: имена, значения по
умолчанию и описания переменных живут в тегах структуры, откуда
библиотека читает окружение и печатает справку.

## What Changes

- `internal/config`: структура `Config` получает теги `env`,
  `env-default`, `env-description`; разбор окружения делает
  `cleanenv.ReadEnv`. Все проверки, которые тегами не выразить
  (различие адресов зон, допустимые имена окружений, положительные
  длительности и счётчики, минимальная длина секретов и токенов,
  обязательность параметров вне development, явный `APP_ENV` в
  Kubernetes, запрет e2e-токена в production), остаются в коде без
  изменения сообщений.
- Семантика пустого значения уточняется: для текстовых переменных
  пустая строка равна отсутствию (применяется значение по умолчанию),
  для чисел, длительностей и булевых пустая строка является
  недопустимым значением и ошибкой старта с именем переменной.
  Раньше пустая строка везде читалась как отсутствие.
- Новая подкоманда `identity-service env` печатает список переменных с
  описаниями и значениями по умолчанию; работает без заданной
  конфигурации.
- Тест `TestDefaultsMatchTags` держит теги и экспортируемые константы
  `Default*` в согласии.
- README: примечание про пустые значения и подкоманду `env`.

Не меняется: имена переменных, значения по умолчанию, обязательность
вне development, тексты ошибок валидации, чарт.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `service-runtime`: требование «Запуск с конфигурацией из окружения»
  дополняется правилом для пустых значений и справкой по переменным.

## Impact

- Новая зависимость `github.com/ilyakaznacheev/cleanenv v1.5.0` (MIT);
  транзитивно `BurntSushi/toml`, `joho/godotenv`,
  `olympos.io/encoding/edn`. Компромисс записан в design.
- `internal/config/config.go`, `internal/config/config_test.go`,
  `cmd/identity-service/main.go`, `README.md`.
- Совместимость: развёртывания, которые экспортируют пустую строку в
  типизированную переменную, перестанут стартовать с явной ошибкой.
  В чартах репозитория таких значений нет.
